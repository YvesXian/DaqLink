# DaqLink
1. 軟體開發與架構設計 (Software & Architecture)
* 開發語言與框架：使用 C# .NET Framework 撰寫穩定且高效的 自動化測試程式。
* 程式設計思維：遵循 SOLID 原則 與多種 Design Patterns（設計模式），重視模組化與高擴充性工具的開發。

2. 韌體與硬體整合 (Firmware & Hardware)
* 微控制器 (MCU)：使用 PIC32MX460F512L 開發板進行韌體開發。
* 硬體周邊應用：熟悉 GPIO、ADC、Timer、PWM、SPI、UART 等基礎周邊控制。
* 通訊介面：透過 FT232 晶片實現 UART 序列通訊 傳輸。
